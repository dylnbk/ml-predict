# Statistical Models Implementation

This document describes the implementation of ARIMA and Holt-Winters statistical prediction models for the crypto prediction application.

## Overview

Two deterministic statistical models have been added as new AI provider types:
- **ARIMA** (AutoRegressive Integrated Moving Average)
- **Holt-Winters** (Triple Exponential Smoothing)

These models provide deterministic, mathematical forecasting without relying on external APIs, offering an alternative to AI-based predictions.

## Implementation Details

### Files Created/Modified

1. **`utils/statisticalModels.js`** - Core statistical models implementation
2. **`services/predictionService.js`** - Modified to support statistical models as AI providers

### New AI Provider Types

The following new provider types are now available:
- `'arima'` - ARIMA statistical model
- `'holt_winters'` - Holt-Winters statistical model

### Database Integration

Statistical models are fully integrated with the existing database structure:
- Predictions stored in the same `predictions` table
- Model versions: `'arima-statistical-model'` and `'holt-winters-statistical-model'`
- Compatible with existing accuracy tracking and rolling prediction logic

## Model Specifications

### ARIMA Model

**Type**: AutoRegressive Integrated Moving Average (1,1,1)

**Features**:
- Uses historical price patterns and autocorrelation
- Implements first-order differencing for stationarity
- Good for trending data with momentum
- Includes trend component with exponential decay
- Mean reversion for long-term stability

**Parameters**:
- AR coefficient: Estimated from consecutive differences correlation
- MA coefficient: Estimated from residuals correlation
- Trend: Calculated from recent price slope with dampening

### Holt-Winters Model

**Type**: Triple Exponential Smoothing

**Features**:
- Handles level, trend, and seasonal components
- Adaptive smoothing parameters optimized for crypto volatility
- Seasonal cycles based on time interval:
  - 1h interval: 24-hour daily cycle
  - 4h interval: 6-period daily cycle  
  - 1d interval: 7-day weekly cycle

**Parameters**:
- Alpha (level): 0.3
- Beta (trend): 0.1
- Gamma (seasonal): 0.2

## Usage Examples

### Basic Usage

```javascript
const PredictionService = require('./services/predictionService');
const service = new PredictionService();

// Generate ARIMA predictions
const arimaResult = await service.generatePredictions('BTC', '1h', 'arima', 3, 24);

// Generate Holt-Winters predictions
const hwResult = await service.generatePredictions('BTC', '1h', 'holt_winters', 3, 24);
```

### Rolling Predictions

```javascript
// Works with existing rolling prediction logic
const rollingResult = await service.generateRollingPredictions('BTC', '1h', 'arima');
```

### Retrieving Predictions

```javascript
// Get predictions using existing method
const predictions = await service.getPredictions('BTC', '1h', 'arima');
```

## Data Requirements

### Minimum Data Requirements
- **ARIMA**: Minimum 10 historical data points
- **Holt-Winters**: Minimum 24 historical data points

### Optimal Data Usage
- Both models use up to 500 historical kline data points
- More data generally improves model accuracy
- Models automatically handle varying data lengths

## Output Format

Both models generate predictions in the standard format:
